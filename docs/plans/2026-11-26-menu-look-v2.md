## Command and data changes
- **Commands:** none. `STATE_FORMAT`, the state hash and the defs hash are unchanged.
- **Save:** one key in `MenuPrefs`' section, the loading tip counter (an int, default 0, P668). It
  is meta, never sim state, and it needs no new save version.
- **Meta:** one read-only helper on `Progression`, written in P670. It lists the
  `ProgressionDef.unlocks` entries whose rank lies in (old rank, new rank]. It uses integer
  arithmetic and adds no saved state.
- **Theme:**
  - `Menu*` values: square corners, 1 px `border`, the 2 px amber first-item bar, item rest fill
    `ground` at 50 %, the primary and secondary looks, chips.
  - The menu whites move to `text`.
  - New `MenuScrim` tokens: the `Læseskygge` gradient stops and the `Kontrastlag` tint.
  - No type is renamed.
- **Art:**
  - Two backdrops, menu and loading, each in a wide and a tall crop.
  - Two hero portraits.
  - One arrow glyph SVG of our own.

## Risks
1. **The read-out is partial.** P602 did not read the Intro and the portrait boards by text.
   P661 reads them first. If they show a layout that conflicts with ADR 0052 §2, P662 waits and
   the architect adds a note.
2. **Resemblance and ownership of the AI pictures** (ADR 0051 §5). The screen lowers the risk of
   a look close to another game. It does not remove it. No prompt names a game, a studio or a
   brand.
3. **Memory and web size.**
   - Four backdrop crops and two portraits add to the web download.
   - A full-screen texture costs about 8 MB of GPU memory while it is shown.
   - The loading backdrop is up during the atlas bake, which is the peak. P668 releases it on
     close, and P671 reads the peak on the phone's perf card.
   - Lever: a smaller crop, or one shared picture for menu and loading.
4. **Text over a busy picture.** The white-pixel contrast rule holds for any picture, but it
   makes the scrim dark at the text column. Michael judges the balance in P671.
5. **Scope creep from the file.** The file's features (§2 item 10) go to the follow-up list,
   not into a row.
6. **`theme.tres` friction** with lane H. Disjoint blocks and a combined-tree verify handle it.
