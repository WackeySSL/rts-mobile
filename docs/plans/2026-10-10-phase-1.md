Date: 2026-10-10. Decisions: `docs/adr/0003-phase-1-sim-skeleton.md`,
`docs/adr/0004-touch-gestures-and-ui-scale.md`, `docs/adr/0005-android-debug-apk-ci.md`.
Base: `main` at `dbb9ed5`. Each PR branches from `main` after its dependencies have merged.

## Goal
Every Phase 1 box in `docs/ROADMAP.md` is met on `main`:
- The boot scene is a 48x48 map with 30 blue tanks and 10 red targets.
- Camera: pan, pinch to 3 levels, two-finger pan, edge clamp.
- Selection by tap, double-tap, box, "All army" and groups 1-3.
- Taps on ground issue attack-move Commands that spread the units around the point, with a
  marker.
- Every tappable thing is at least `UiScale.dp(48)`, proven by tests in `tests/input/` and
  `tests/ui/`.
- Every CI run uploads an arm64 debug APK.

Then Michael runs the gate: 3 days on his 6-inch phone, using the web preview and the APK.
No combat, fog, flow fields, state hash, sound or AI in this phase (ADR 0003 §1).

## Command and data changes
- **Command v0** (ADR 0003 §2-3): one type, `ATTACK_MOVE`, with a target point in milli-tiles.
  Humans submit it through `CommandQueue.submit()`. `MatchRunner` stamps `tick` and `sequence`.
  Selection and groups are not Commands (ADR 0003 §8).
- **New data:**
  - `data/units/light_tank.tres` (speed 120, radius 400, selection_radius 500,
    formation_spacing 1200, all milli-tiles or milli-tiles per tick).
  - `data/scenarios/controls_test.tres` (48x48 map, local player 1, camera start, spawns:
    30 tanks for player 1 and 10 for player 2).
  - `data/input_settings.tres` (gesture thresholds, zoom levels, haptics; ADR 0004 §2).
- No balance number lives in code. View constants that are not balance (64 px per tile,
  colours, ring widths in dp) are exported properties or constants in view scripts.

## Interface contracts (all PRs code against these)
Every `class_name` script is PascalCase. Every other script and scene is snake_case
(ADR 0002 §2). "base px" means canvas units under `canvas_items` stretch: Control sizes and
input positions. "milli" means milli-tiles.

| Item | Contract |
| --- | --- |
| `Sim` | `game/sim/Sim.gd`, `class_name Sim extends RefCounted`. `const TICK_RATE: int = 15`, `const MILLI_PER_TILE: int = 1000`. `static func step(world: World, commands: Array[Command]) -> void`: sorts `commands` in place with `Command.compare`, applies the commands whose `tick == world.tick` (others dropped and counted), moves units, then `world.tick += 1`. Rules: ADR 0003 §3-5 |
| `Command` | `game/sim/Command.gd`, `class_name Command extends RefCounted`. `enum Type { NONE = 0, ATTACK_MOVE = 1 }`. | `World` | `game/sim/World.gd`, `class_name World extends RefCounted`. `enum Order { IDLE = 0, ATTACK_MOVE = 1 }`. `var tick: int`, `map_w: int`, `map_h: int` (milli), `next_id: int = 1`, `dropped_commands: int`. Per unit, ascending id: `unit_id`, `owner`, `type_index`, `pos_x`, `pos_y`, `goal_x`, `goal_y`, `order: PackedInt32Array`. `func unit_count() -> int`, `func index_of(id: int) -> int` (-1 when unknown), `func add_unit(owner: int, type_index: int, x: int, y: int) -> int` (returns the new id), `static func from_scenario(scenario: ScenarioDef) -> World`. View and input only read a World. They never write to it |
| `FixedMath` | `game/sim/FixedMath.gd`, `class_name FixedMath extends RefCounted`. `static func isqrt(n: int) -> int`: floor square root, 0 for n <= 0, integers only |
| `Formation` | `game/sim/Formation.gd`, `class_name Formation extends RefCounted`. `static func assign(world: World, unit_indices: PackedInt32Array, target_x: int, target_y: int) -> void`: sets `goal_x/goal_y` of the given unit indices (ADR 0003 §4). | `MatchRunner` | `game/core/MatchRunner.gd`, `class_name MatchRunner extends Node`. `@export var scenario: ScenarioDef`, `@export var max_catch_up_ticks: int = 4`. `var world: World`, `var prev_pos_x`, `prev_pos_y: PackedInt32Array` (positions before the last tick, same indices), `var paused: bool`. `signal ticked(tick: int)`. `func start() -> void` (builds the world, clears CommandQueue; `_ready` calls it when `scenario` is set), `func run_ticks(n: int) -> void` (synchronous, ignores time), `func alpha() -> float` (0..1, fraction of the next tick elapsed). ## Risks
1. **The Android export is unverified** (no SDK reachable from cloud sessions). The editor
   settings might not pick up `JAVA_HOME`/`ANDROID_HOME`, the build-tools choice may differ, or
   the runner image may change. Mitigation: the P18 CI spike first, and loud checks with exit 4.
2. **The `UiScale` web formula comes from source, not from a device.** Mitigation: the touch
   probe and Michael's ruler check in P6, compared native against web after P18. A wrong
   factor gets a new ADR.
3. **v0 sim shapes may change in Phase 2.** Mitigation: a small surface, and tests that pin
   behaviour rather than layout (ADR 0003 Consequences).
4. **Units overlap while moving** (no separation). That may hurt "moves groups without
   thinking". Mitigation: centre-out greedy slots. If the gate says so, separation moves
   forward through an ADR.
5. **Thresholds feel wrong for thumbs**: 12 dp slop, 300 ms long-press and 300 ms double-tap
   are reasonable defaults, not measurements. Mitigation: everything is in data, and the
   probe log shows what the recognizer saw.
6. **Accidental orders**: every ground tap with a selection moves units. Mitigation: the
   48 dp hit area, own-units-only picking without a selection, and the open question about
   deselecting.
7. **Zoom 1.5 looks soft** with the 0.5 SVG import scale (STYLE.md already warns about
   upscaling). Mitigation: the P12 gallery row and open question 4.
8. **Generated debug keys** force an uninstall before each APK update. Mitigation: the
   optional secrets for `main` builds (P19).
9. **Static override state** in `UiScale` can leak between suites. Mitigation: every suite
   clears it in `after_test`. A leak shows up as profile-dependent failures in unrelated
   suites, and qa checks for it when a test flakes.
10. **The critical path is serial** (12 touch-ux-dev PRs under a two-thread limit, and each
    merge waits for Michael's "merge"). Mitigation: lane B fills the second thread. Michael
    may allow a third thread for lane A's independent pair P7/P9 (open question 10).
11. **Scope creep**: no sound, no info card, no combat, no minimap, no camera-centring on group
    double-tap, no telemetry. Any of those needs a plan change first.
12. **Licence obligations for a public APK**: `THIRD_PARTY_LICENSES.txt` goes with every
    artifact and release, and the CREDITS row covers the default launcher icon.
