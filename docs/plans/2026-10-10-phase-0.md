# Plan: Phase 0 (Foundation)

Date: 2026-10-10. Decisions: `docs/adr/0002-phase-0-foundation.md`. Branch: `phase-0`.

## Goal
Every Phase 0 box in `docs/ROADMAP.md` is met. `bash scripts/verify.sh` prints `RESULT: GREEN`
locally. One PR has a green CI run and a green preview run, where green means the preview is
live (the preview job fails when it is not), and the preview link opens the dev menu on
Michael's phone. Preview cleanup and the gate are proven after the merge (step 10). No gameplay
or sim code is written in this phase.

## Affected modules
- Root: `project.godot`, `export_presets.cfg`, `.gitignore`.
- `game/core/` (new, see ADR 0002 §1), `game/view/`, `game/ui/`, plus empty `game/{sim,input,ai,ads,meta}`, `data/`.
- `scenes/main.tscn`, `scenes/dev/`, `assets/art/`, `addons/gdUnit4/`, `tests/`.
- `scripts/`: `run-tests.sh`, `run-sim-smoke.sh` and `export-web.sh` (new), plus `verify.sh` (one line); `.github/workflows/` and `scripts/ci/` (new).

## Command and data changes
None. There is no Command type and no `data/*.tres` yet. The test map size, tile size and
colours are exported properties set in `scenes/main.tscn`. They are not balance numbers, and
Phase 2 replaces them with sim map data.

## Risks
1. **Silent Godot failures** (exit 0). Mitigated by the log scan everywhere, the results.xml
   check, the script-compile test and the artifact checks.
2. **gdUnit4 v6.2.2 is outside its stated range (4.5-4.7.1).** It is verified on 4.7.2
   (macOS) but not on Ubuntu. If CI breaks, the fallback is v6.2.1, which needs a new ADR.
3. **Phone touch.** Buttons are verified only engine-side. If they fail on the phone, flip
   `emulate_mouse_from_touch` per ADR 0002 §4.
4. **Pages from GITHUB_TOKEN pushes.** The docs say these do not trigger a build. The fallback
   is the `pages/builds` API call. Pages is set up before the PR (step 5), so the first preview
   run is a real test; a timeout fails the job.
5. **The 4.7 editor rewrites `res://` autoload and main-scene paths to `uid://`.** The project-settings test
   pins `res://`. Revert such rewrites unless an ADR changes the rule.
6. **Case-sensitive paths.** PascalCase class files work on macOS and break on Linux CI and
   Android if a `preload` path differs in case. CI catches it.
7. **SVG import scale 0.5** may look soft on 1.5x phone screens. Judge it in the gallery. A
   change needs a STYLE.md update approved by Michael.
8. **The preview job holds a write token while running PR code.** Fork PRs are skipped and no
   secrets are present. Revisit in Phase 6.
9. **Docs drift on `DetRng`.** Skill, agent and roadmap text still say `DetRng` for the sim RNG
   until Michael approves the step 7 issue. A Phase 2 agent following them hits the purity test
   or the autoload/class_name collision. The issue blocks the Phase 2 plan.
10. **120 base px dev buttons are large** (1/6 of the screen height). Accepted for dev-only UI;
    Phase 1's `UiScale.dp(48)` replaces the number.
11. **Scope creep.** No gesture recognizer, `UiScale`, sim classes or data resources in Phase 0.
    Those belong to Phases 1 and 2.
