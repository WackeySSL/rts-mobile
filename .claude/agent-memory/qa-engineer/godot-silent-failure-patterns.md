One or two lines each. Found during Phase 0 (2026-10-10).

- Godot exits 0 on parse errors and when gdUnit4 finds no tests. `run-tests.sh` therefore checks `results.xml` for tests>0, and `verify.sh`/`export-web.sh` scan the log for `SCRIPT ERROR|^ERROR:|Parse Error`.
- `load()` of a broken script only prints a Parse Error; `test_scripts_compile` calls `can_instantiate()` on every `.gd` to turn that into a real failure.
- Headless window is 64x64: GUI hit-tests silently miss. Set `get_window().size = Vector2i(1280, 720)` first and restore it in `after()`.
- An expected `push_error` still prints `ERROR:` and fails the verify scan, even under `assert_error`. Do not test error paths without a narrow allowlist entry.
- `grep -q` at the end of a pipeline under `pipefail` can fail from SIGPIPE: read the output into a variable and use a here-string.
- `git branch -d` refuses after cherry-picks (new SHAs). Prove equivalence with `git patch-id --stable` per commit, then `-D`.
- `strings pack | grep dev_menu` matches file paths; the real check is `grep -A1 -x _custom_features | grep -qx dev_menu`.
- The interactive shell is zsh: unquoted `$var` is not word-split and `PIPESTATUS` is `pipestatus`. Run arg-matrix loops under `bash -c`.
- gdUnit4 and worktrees share `user://` (same project name): never run gdUnit4 in two worktrees at once.
- `grep -v -E -f allowlist || true` exits 2 on an invalid ERE and hides every error. verify.sh and export-web.sh now compile it first with `grep -E -f allowlist /dev/null` (exit > 1 = fail). Proof harness pattern: scratch git repo + fake `godot` on PATH.
- A test that skips a scene/file "while it does not exist" goes vacuous once the file moves. Require it by `DevRoutes.*` constants. Prove such fixes by moving the file and running old vs new tests.
- In-memory `GDScript.new()` fixtures must be valid code: a parse error prints `SCRIPT ERROR` (fails the verify scan) and `get_instance_base_type()` returns "".
- zsh traps in the Bash tool: `grep` is a ugrep function (use /usr/bin/grep for BSD behaviour), and an unmatched glob (`rm -f x_*.uid`) aborts the whole command.
- The allowlist must never fail open: verify.sh and export-web.sh reject invalid ERE syntax (grep exit 2) and entries that match an empty line (`a*`, `x?`, `.*`, GNU `foo|`). An over-broad but valid entry (e.g. `ERROR`) is still possible, so review every new entry.
- Integrating fix branches: commit a dirty memory file before `git cherry-pick`, prove equivalence with a per-commit `git patch-id --stable` match, then `git worktree remove` (no --force needed when only ignored `.godot/build/reports` remain) and `git branch -D`.
- Purity guard limit: name patterns cannot tell `Array.shuffle()`/`pick_random()` from a `DetRandom.shuffle()`, so those are not banned. `floor/ceil/round/lerp` on ints return ints, so they are not banned either (only `*f` variants).
- Purity guard (P27q): `length(` also trips on `String.length()`; use `len(s)` in game/sim (the report now says so). Multi-line scan fixtures live as `.txt` under `tests/project/fixtures/` so gdformat, gdlint and the compile test never see them; pin flagged line numbers and append new cases at the end.
- Text scanners that track brackets must count depth relative to the construct they track (a loop header inside a multi-line lambda call, or after a docstring with a stray `(`, was skipped silently with an absolute count). Pin every operator and keyword of a detection regex with its own one-line snippet, then delete one token at a time to prove each pin fails.
- Word-list scanners (P56, `test_native_purity`): build each regex from the same word list the test probes, one generated fixture per word. Hand-written alternations left 134 of 213 alternative-deletion mutants alive; a scratch SceneTree script that deletes one alternative at a time finds them. A legal look-alike per rule also catches over-broad words (`exp\w*` matched `std::experimental`). Probes generated from the list die with a deleted word (review: 125 of 128 word and 23 of 36 row deletions survived), so also pin hand-written snippets of every ADR-named ban (`PINNED`) and the total word count (`BANNED_WORDS`).
- C++ text scans (P56): a `const` exemption must not skip `static const StringName n("x")` (lazily built on the worker) or `static const T *p` (mutable pointer); a `constexpr` exemption must cover variables only, not function bodies or `if constexpr`; godot-cpp headers pull in `<cmath>` and `<atomic>`, so in bind/ ban the words, not only the includes. scons leaves `.os` files in `native/sim_kernels/src/`: a "no stray file" check filters by C/C++ extension.
- C++ text scans (P56 final check): a fact that spans files (the pointer names of `WorldView` in `core/world_view.h`, used in `core/flow.cpp`) must be collected over the whole tree before any file is judged, and the fixtures need a multi-file form (a `---` line) with the use before and after the view; a per-file scan passed the real layout. Exempt by character range, not by line (a line exemption leaked to the rest of the line), and test `constexpr` as a word (`__cpp_constexpr` is not one). A `static` hit cannot be told from a function declaration by regex once a `(` or `=` follows: inside any block that is not a namespace, struct, class or union it is always a variable; elsewhere only an initializer before the first `(` says so. Suffix every cmath shape with `[fl]?` (`sqrtf`, `std::sqrtl`).
- A scratch `-s` SceneTree script that errors in `_init()` never reaches `quit()` and hangs headless Godot (a renamed constant did it): run it under `timeout`. GDScript `String` has no `partition()`; use `find()` and `substr()`.
- C++ view scan (P56b): judge a view's members by walking its body at brace depth 1 (labels set the section and end the member before them; a struct starts public and a class private; only `private:` is exempt, a protected pointer is read raw by a derived class). A member ends at `;`, `,` or `}` outside parentheses whatever its head; the head (first `= ( [ { ; ,`) only bounds the pointer search and says function (`(`) or data. Ending a function by `code[head] == "("` swallowed the next member and its `private:` after `operator[]`, `operator==`, `[[nodiscard]]` or `template <typename U = T>` (false positives and misses, P56b review): blank attributes and preprocessor lines first, one flagged and one legal fixture per such shape, and mutate every branch (a survivor means a missing fixture). A fixture of another rule must use a `class` view or it trips the public-pointer rule as well (fixtures trip exactly one rule).
- Suite order (P56c): gdUnit4 scans a directory in file-system order, which differs per machine (P26n2: an exit leak was green locally, red on CI). `run-tests.sh` expands each `-a <dir>` into `-a <file>` args in `LC_ALL=C` byte order; gdUnit4 runs `-a` files in argument order (checked in results.xml and the console). Test it with a fake `godot`, `find` and `sort` that call the real tool through `env PATH=$STUB_REAL_PATH` and exit 97 when re-entered: a stub that finds itself through PATH loops forever.
- Exit leak (P56c, final rule): an inner class with a script base (a `class_name` script such as SimProbe, an `extends "res://..."` path, another inner class, a dotted `Outer.Inner`) that names a class it sits in leaves every script alive at exit once an earlier suite names that base (144 ObjectDB instances, 101 resources, ERROR lines, exit 0; `-a A -a B` leaks, `-a B -a A` does not). Two rounds of scanning the body for the shapes (`X.new()`, `is`, `as`, `Array[X]`, a bare `X`, `static var`, `X.Base.new()` of a preloaded base, `extends Outer.Slow`, `@abstract`, a preload of the own path) each left new ones; RefCounted, Node, Object, Logger, CanvasGroup, HBoxContainer, no base and a GDExtension class were clean for all of them. So `test_inner_classes_extend_engine_classes` tests the base (ClassDB.class_exists, any depth): a class with a script base goes in its own file (it moved TwoTypeLayer). When a guard keeps losing to new shapes, find what every measured leak shares and test that.
- Scan details (P56c fix 3): lex strings and comments in one left-to-right regex (`(?s)`, triple quotes first): Godot accepts a line break inside a quoted string, and a `\` that ends a comment continues nothing. `class A: extends B`, `@abstract class A:` and a `\` inside the class line parse; an `extends` after another member does not ("Unexpected extends in class body"). Measure parse acceptance with `GDScript.new()`, `source_code`, `reload()` in a `-s` script under `timeout`. A mutant that survives is a missing fixture: a comment with two apostrophes killed the "comments kept" mutant, a string with escaped quotes and a line break the "escape ignored" one.
- gdlint `max-file-lines` is 1000: `test_native_purity.gd` sits at 995, so a pinned-limits test for it needs the scan moved to `tests/support/` first. `bash scripts/verify.sh --help` runs the whole verify (it takes no flags): never probe it that way.
- Perf harness (P38p): time only `loop.step` and read phases, stats and projectiles after the clock stops; pin a printed line with a clockless suite on fake samples (exact string, ranks on a shuffled 200-tick series so p98/p99 and p49/p50 mutants die; 30 ticks cannot tell p98 from p99), and assert only inequalities that hold per run (phase sum <= mean, p50 <= p95, max <= worst window), never `p95 >= mean`. A function with an `Array[Dictionary]` parameter fails at run time when given an untyped literal `[a, b]` (SCRIPT ERROR, caught only by running it): build a typed local first.
- Mutation sweeps (P38p): `sed` a mutant, run one suite, restore from a backup (`mutate.sh` in the scratchpad); scope a loop mutant by a `/start/,/end/` address range or the test that repeats the loop is mutated too and survives. Regex word lists: a scratch `-s` script that deletes each alternative and widens each `\b`, `\s*` and `^` finds missing look-alikes (`has_signal`, `RecursiveMutex`, `parse_str_to_var`, `world._emit(`); the engine coerces a float in an int `.tres` field, so `ref_iterations = 1000.5` is an equivalent mutant.
- Keyword bans (P38p fix 1): a `^\s*signal` rule misses `@warning_ignore("unused_signal") signal x` and `class A: signal x`, which Godot accepts; a reserved word needs only `\b` once strings and comments are stripped. Probe the end to end path too (append the form to a real game/sim file and run the scan).
- Data-file tests (P38p fix 1): do not pin a field count or a short exempt list (the next PR that adds a field turns the suite red): exempt by name prefix, guard against vacuity with `>=`, and read the .tres text for a `name = ` line, since a deleted line loads as the script default and passes an equality with `Def.new()`. Godot's ResourceSaver drops default-valued script properties, so such a file is edited as text.

**Why:** each of these cost a spike or a false GREEN during Phase 0.
**How to apply:** check this list first when a test is flaky or a script reports success without evidence. Never relax the scan; add a narrow allowlist regex with a comment only for a message proven benign.
